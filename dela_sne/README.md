# DELA-SNE practical example

## Objective

Demonstrate the proposed locally adaptive stochastic-neighbor embedding after the mathematical definition is frozen in the manuscript.

## Recommended design

Reuse the benchmark data and preprocessing adopted for the LAC and t-SNE examples when possible. Expose the locally adaptive metric quantities explicitly and separate embedding evaluation from clustering evaluation.

## Target artifacts

- `example.ipynb` — executable walkthrough.
- `figures/` — figures generated by the notebook.
- `results/` — optional machine-readable outputs.

The notebook must track the corresponding manuscript equations so that implementation changes can be audited against the formal definition.
