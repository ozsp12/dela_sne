# Algorithms

The project is organized around three algorithms.

| Algorithm | Category | Purpose in this repository |
|---|---|---|
| [LAC](lac.md) | Clustering | Establish locally adaptive feature weighting and cluster-specific metrics. |
| [t-SNE](tsne.md) | Dimensionality reduction / embedding | Establish the stochastic-neighbor embedding framework used for visualization. |
| [DELA-SNE](dela-sne.md) | Proposed embedding method | Investigate locally adaptive metrics within an entropy-based stochastic-neighbor formulation. |

This separation is important: a visually separated t-SNE embedding is not, by itself, a clustering result.
