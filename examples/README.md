# Examples

This directory contains one practical, reproducible example for each central algorithm in the project:

- `lac/` — Locally Adaptive Clustering.
- `tsne/` — t-distributed Stochastic Neighbor Embedding.
- `dela_sne/` — proposed DELA-SNE method.

The examples should share datasets and preprocessing whenever scientifically appropriate. This makes differences in behavior attributable to the methods rather than to unrelated experimental choices.
