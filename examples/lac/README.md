# LAC practical example

## Objective

Demonstrate how locally adaptive clustering assigns different relevance to features in different clusters.

## Recommended design

Use a low-sample synthetic dataset containing informative dimensions together with nuisance dimensions. Report the cluster assignments, learned feature weights, convergence behavior, and a compact visualization.

## Target artifacts

- `example.ipynb` — executable walkthrough.
- `figures/` — figures generated by the notebook.
- `results/` — optional machine-readable outputs.

The example should reproduce the mathematical notation used in the manuscript whenever possible.
