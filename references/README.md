# References

This directory is reserved for the scientific literature used in the DELA-SNE project.

## Recommended contents

- `references.bib` — canonical BibTeX database used by the repository and manuscript.
- legally redistributable preprints, author manuscripts, or open-access papers when useful for the project;
- short notes that map a reference to the specific equations or concepts used in the manuscript.

Because this is a public repository, publisher PDFs should not be committed unless their license explicitly permits redistribution.
