# t-SNE practical example

## Objective

Demonstrate stochastic-neighbor embedding on a controlled high-dimensional dataset and make clear that the output is an embedding rather than a clustering assignment.

## Recommended design

Record preprocessing, perplexity, learning rate, initialization, number of iterations, and random seed. Compare the original data geometry with the two-dimensional embedding and discuss which interpretations are justified.

## Target artifacts

- `example.ipynb` — executable walkthrough.
- `figures/` — figures generated by the notebook.
- `results/` — optional machine-readable outputs.
